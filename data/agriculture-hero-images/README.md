# Agriculture agency hero image set

This package contains eight wide, natural agriculture photographs selected for website hero sections. The `hero-ready` folder contains 1600×900 crops suitable for a left-to-right half-screen hero layout. The `originals` folder preserves the downloaded source crops.

## Order and intended use

1. Soil analysis and restorative treatment
2. Connected tools and reporting
3. Agricultural advisory
4. Efficient irrigation
5. Predictive farm models
6. Crop risk analytics
7. AI irrigation command
8. Homepage agriculture landscape
